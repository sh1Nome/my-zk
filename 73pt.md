---
title: pacman の使い方
tags: [linux, arch, package]
---

| 操作                                                             | コマンド                     |
| ---------------------------------------------------------------- | ---------------------------- |
| すべてのインストール済みパッケージを表示する                     | `pacman -Q`                  |
| 明示的にインストールしたパッケージのみ表示する                   | `pacman -Qe`                 |
| インストール済みパッケージを検索する                             | `pacman -Qs (パッケージ)`    |
| パッケージを検索する                                             | `pacman -Ss (パッケージ)`    |
| パッケージの情報を表示する                                       | `pacman -Si (パッケージ)`    |
| パッケージをインストールする                                     | `pacman -S (パッケージ)`     |
| システム全体をアップデートする                                   | `pacman -Syu`                |
| パッケージを依存関係も含めて削除する                             | `pacman -Rs (パッケージ)`    |
| 依存関係としてインストールされたが現在不要なパッケージを表示する | `pacman -Qdtq`               |
| 不要なパッケージを削除する                                       | `pacman -Rs $(pacman -Qdtq)` |
| リポジトリ情報など pacman の設定を表示する                       | `pacman-conf`                |
