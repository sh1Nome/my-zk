---
title: Linux のユーザーの設定方法
tags: [linux, command]
---

| 操作                                                     | コマンド                        |
| -------------------------------------------------------- | ------------------------------- |
| vi で visudo を実行する                                  | `EDITOR=vi visudo`              |
| 現在のユーザーのパスワードを変更する                     | `passwd`                        |
| 指定したユーザーのパスワードを変更する（root権限が必要） | `passwd (ユーザー名)`           |
| sudoグループにユーザーを追加する                         | `usermod -aG sudo (ユーザー名)` |
