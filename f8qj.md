---
title: apt の使い方
tags: [linux, debian, package]
---

| 操作                                                                                             | コマンド                     |
| ------------------------------------------------------------------------------------------------ | ---------------------------- |
| パッケージリストを更新する                                                                       | `apt update`                 |
| インストール済みパッケージを更新する                                                             | `apt upgrade`                |
| パッケージをインストールする                                                                     | `apt install (パッケージ名)` |
| パッケージを削除する（設定ファイルは残る）                                                       | `apt remove (パッケージ名)`  |
| パッケージと設定ファイルを完全に削除する                                                         | `apt purge (パッケージ名)`   |
| 自動インストールとマークされているもののうち、どのパッケージからも依存されていないものを削除する | `apt autoremove`             |
| 削除されるパッケージを実際に削除せずに確認する                                                   | `apt autoremove --dry-run`   |
| インストール済みパッケージ一覧を表示する                                                         | `apt list --installed`       |
| アップグレード可能なパッケージ一覧を表示する                                                     | `apt list --upgradable`      |
| パッケージを検索する                                                                             | `apt search (パッケージ名)`  |
| パッケージの詳細情報を表示する                                                                   | `apt show (パッケージ名)`    |
