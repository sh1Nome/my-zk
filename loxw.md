---
title: bash のキーバインド
tags: [bash]
---

`bind -P` でキーバインドの一覧を表示できる。

| 操作                                         | キー                           |
| -------------------------------------------- | ------------------------------ |
| カーソル位置から直前の単語の先頭まで削除する | `<C-w>`                        |
| カーソル位置から行頭まで削除する             | `<C-u>`                        |
| カーソル位置から行末まで削除する             | `<C-k>`                        |
| カーソルを1文字右に移動する                  | `<C-f>`, `<RIGHT>`             |
| カーソルを1文字左に移動する                  | `<C-b>`, `<LEFT>`              |
| カーソルを次の単語の先頭に移動する           | `<A-f>`, `<ESC>f`, `<C-RIGHT>` |
| カーソルを前の単語の先頭に移動する           | `<A-b>`, `<ESC>b`, `<C-LEFT>`  |
| カーソルを行頭に移動する                     | `<C-a>`, `<HOME>`              |
| カーソルを行末に移動する                     | `<C-e>`, `<END>`               |
| 改行する                                     | `<C-j>`                        |
| 次のコマンド履歴を表示する                   | `<C-n>`                        |
| 前のコマンド履歴を表示する                   | `<C-p>`                        |
| コマンド履歴を検索する                       | `<C-r>`                        |
| コマンドやファイル名を補完する               | `<TAB>`                        |
