## 操作方法

| 操作                                                 | コマンド                            |
| ---------------------------------------------------- | ----------------------------------- |
| ファイルを検索パターンで検索する                     | `rg (検索パターン)`                 |
| 大文字小文字を無視する                               | `rg -i`                             |
| マッチしないものを出力する                           | `rg -v`                             |
| 特定のパターンに一致するファイルのみを検索対象にする | `rg -g (globパターン) (検索文字列)` |

## glob パターン

| 条件                       | パターン   |
| -------------------------- | ---------- |
| txtファイルのみ            | `*.txt`    |
| txtファイル以外            | `!*.txt`   |
| srcディレクトリ以下すべて  | `src/**`   |
| distディレクトリ以下を除外 | `!dist/**` |
