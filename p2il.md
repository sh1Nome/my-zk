---
title: top の使い方
tags: [linux, command]
---

| 操作                                                           | コマンド | 互換性のために残っている |
| -------------------------------------------------------------- | -------- | ------------------------ |
| ソートキーを切り替えたり、カラムの表示／非表示を切り替えられる | `f`      | -                        |
| ソートを反転する                                               | `R`      | -                        |
| ソートキーをメモリに変更                                       | `M`      | Yes                      |
| ソートキーをPIDに変更                                          | `N`      | Yes                      |
| ソートキーをCPUに変更                                          | `P`      | Yes                      |
