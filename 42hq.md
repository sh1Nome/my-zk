title: zellij のキーバインド
tags: [zellij]
---

[Unlock-First](https://zellij.dev/documentation/keybinding-presets.html) プリセットを使っている。  
以下はステータスバーにヒントが出ないかつよく使うもの。

| 操作                         | キー                        |
| ---------------------------- | --------------------------- |
| pane を選択する              | Alt + p                     |
| pane が属する tab を移動する | Tab モードで `[` または `]` |
| tab を移動する               | `Alt + i`, `Alt + o`        |
