---
title: Linux でコマンド情報を見る
tags: [linux, command]
---

| 操作                                                   | コマンド            |
| ------------------------------------------------------ | ------------------- |
| 指定したコマンドについて表示する（コマンドの場所など） | `type (コマンド)`   |
| 指定したコマンドのパスを表示する                       | `which (コマンド)`  |
| コマンドのマニュアルを表示する                         | `man (コマンド)`    |
| マニュアルファイルのパスを表示する                     | `man -w (コマンド)` |
| コマンドのヘルプを見る（必ず実装しているとは限らない） | `(コマンド) --help` |
