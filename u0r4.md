---
title: grep の使い方
tags: [linux, command]
---

| 操作                                 | コマンド                          |
| ------------------------------------ | --------------------------------- |
| ファイルを検索文字列で検索する       | `grep (検索文字列) (ファイル名)`  |
| コマンド結果を検索文字列で検索する   | `(コマンド) \| grep (検索文字列)` |
| 大文字小文字を無視する               | `grep -i`                         |
| マッチしないものを出力する           | `grep -v`                         |
| 拡張正規表現を使う                   | `grep -E`                         |
| マッチした行の後(行数)行を表示する   | `grep -A (行数)`                  |
| マッチした行の前(行数)行を表示する   | `grep -B (行数)`                  |
| マッチした行の前後(行数)行を表示する | `grep -C (行数)`                  |
