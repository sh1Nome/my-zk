---
title: Java のアクセス修飾子について
tags: [java]
---

| アクセス修飾子 | 意味                                   |
| -------------- | -------------------------------------- |
| public         | 公開                                   |
| protected      | 同じクラスとサブクラスからアクセス可能 |
| -              | 同じパッケージからアクセス可能         |
| private        | 同じクラスからアクセス可能             |
