---
title: ssh でリモートの端末を操作する豊富
tags: [linux, command]
---

| 操作                                                           | コマンド                                                                       |
| -------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| `ed25519`アルゴリズムでSSH鍵を作成する                         | `ssh-keygen -t ed25519 -C "hoge@example.com"`                                  |
| SSH接続する                                                    | `ssh (ユーザー名)@(ホスト名)`                                                  |
| 秘密鍵を使ってSSH接続する                                      | `ssh -i (秘密鍵のパス) (ユーザー名)@(ホスト名)`                                |
| ファイルをダウンロードする                                     | `scp (ユーザー名)@(ホスト名):(コピー元) (コピー先)`                            |
| 秘密鍵を使いファイルをアップロードする                         | `scp -i (秘密鍵のパス) (コピー元) (ユーザー名)@(ホスト名):(コピー先)`          |
| ディレクトリをアップロードする                                 | `scp -r (コピー元ディレクトリ) (ユーザー名)@(ホスト名):(コピー先ディレクトリ)` |
| 擬似端末を割り当てを無効にする、 GitHub への疎通確認とかで使う | `ssh -T (ユーザー名)@(ホスト名)`                                               |
| 実際には接続せず `~/.ssh/config` の解釈結果を表示する          | `ssh -G (ユーザー名)@(ホスト名)`                                               |
| 詳細に表示する                                                 | `ssh -v (ユーザー名)@(ホスト名)`                                               |
