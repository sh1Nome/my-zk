---
title: Linux でシステムの情報を確認する
tags: [linux, command]
---

| 操作                                   | コマンド    |
| -------------------------------------- | ----------- |
| アーキテクチャを表示する               | `uname -m`  |
| OSの種類を表示する                     | `uname -s`  |
| ディスク状態を確認する                 | `df -h`     |
| メモリの使用状況を確認する             | `free -h`   |
| 最後に起動した時間を調べる             | `uptime -s` |
| プロセス一覧を表示                     | `ps aux`    |
| プロセスの状態をリアルタイムで表示する | `top`       |
