---
title: Linux のエディターの開き方
tags: [linux, command, editor]
---

| 操作                               | コマンド             |
| ---------------------------------- | -------------------- |
| 指定したファイルをviで開く         | `vi (ファイル名)`    |
| 指定したファイルをviのモードで開く | `vi -R (ファイル名)` |
| 指定したファイルをviのモードで開く | `view (ファイル名)`  |
| 読み取り専用モードで開く           | `nano -v`            |
