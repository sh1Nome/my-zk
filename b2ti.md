---
title: Linux のエディターの開き方
tags: [linux, command, editor]
---

| 操作                                 | コマンド             |
| ------------------------------------ | -------------------- |
| 指定したファイルを vi で開く         | `vi (ファイル名)`    |
| 指定したファイルを vi のモードで開く | `vi -R (ファイル名)` |
| 指定したファイルを vi のモードで開く | `view (ファイル名)`  |
| 標準入力を vim で開く                | `vim -`              |
| 読み取り専用モードで開く             | `nano -v`            |
